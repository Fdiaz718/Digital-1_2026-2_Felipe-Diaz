# Portafolio de entregas - Digital 1

Este es mi repositorio personal para la asignatura de Digital 1. 

Aquí se estarán documentando las tareas individuales que se realicen durante todo el semestre, para el proyecto final de la materia.

## Especificaciones del proyecto
El proyecto grupal consiste en el desarrollo de una consola multijugador implementada en FPGA, utilizando 4 paneles de matrices LED independientes.

Mi trabajo individual y grupal está enfocado en el diseño del driver de pantalla. Como meta final se tiene poder mostrar sprites en movimiento y fondos estáticos, con información recibida desde los módulos de lógica.
